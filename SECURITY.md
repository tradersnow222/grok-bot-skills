# Security Policy

## Report a problem privately

Please do not open a public issue for a security problem. Use
[private vulnerability reporting](https://github.com/tradersnow222/snowstack/security/advisories/new)
on this repository. Include what you found, how to repeat it, and what an attacker could do with it.

You can expect a first reply within a few days.

## What counts

- A skill that installs, enables, or runs something without the user choosing it.
- A script that sends private data anywhere, or reads files it does not need.
- A way for text from an outside listing to act as instructions to the bot.
- A secret, token, or private prompt committed to the repository.

## Supported versions

Only the latest version on `main` gets fixes.
